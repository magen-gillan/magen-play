# Magen Play

A modern Android music player based on [Phonograph Plus](https://github.com/chr56/Phonograph_Plus) by chr_56.

## Features
- Natural numeric sort (1, 2, 10 instead of 1, 10, 2)
- Queue stays in folder when pressing Next
- Auto-scan after permission grant
- MediaStore direct backend (instant loading)
- Custom folder covers (long-press folder → Change folder icon)
- Name-only view mode for folders
- Live settings update (no restart needed)
- Arabic + English language support
- Custom app icon and branding

## Installation
Download the latest APK from [Releases](../../releases) and tap to install.
