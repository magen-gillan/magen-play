# magen-play

مشغل موسيقى محلي مفتوح المصدر لأندرويد بواجهة عربية وتجربة قابلة للتخصيص. يقدّم المشروع حاليًا نموذجًا أوليًا قابلًا للتشغيل لواجهة المكتبة والمشغل المصغر وإعدادات العرض وتحرير بيانات العرض محليًا.

## الحالة الحالية

هذا الإصدار يعمل داخل مشروع Expo SDK 54. يستخدم بيانات تجريبية محلية حتى يمكن اختبار الواجهة والتصفح والتخصيص دون الادعاء بأنه يقرأ مكتبة الجهاز أو يشغّل ملفات صوتية حقيقية. تحفظ الشاشة تعديلات العناوين والألبومات وإعدادات العرض في `AsyncStorage`، وتدعم تجميع العناصر حسب الأغاني أو الألبومات أو المجلدات أو الفنانين.

لا تزال القراءة الفعلية من ملفات الجهاز وتشغيل الصوت في الخلفية بحاجة إلى Native Module لأندرويد يقرأ `MediaStore` ويشغّل Media3 داخل foreground service. كما يحتاج تحرير الوسوم والقص الفعلي إلى طبقة أصلية تتعامل مع صيغ الصوت وصلاحيات Android Storage. لذلك تعرض الواجهة القص كمعاينة صريحة ولا تنشئ ملفًا صوتيًا وهميًا.

## التشغيل

```bash
pnpm install
pnpm dev
```

للفحص المحلي:

```bash
pnpm check
pnpm lint
pnpm test
pnpm format:check
pnpm build
pnpm build:web
pnpm audit:prod
```

يتطلب تشغيل OAuth في الإنتاج متغيرات `OAUTH_SERVER_URL` و`OAUTH_PORTAL_URL` و`JWT_SECRET`، كما يتطلب العميل `EXPO_PUBLIC_OAUTH_PORTAL_URL` و`EXPO_PUBLIC_APP_ID` عند استخدام تسجيل الدخول.

## المزايا الحالية

- اختيار نوع المكتبة: الأغاني، الألبومات، المجلدات، أو الفنانون.
- بحث محلي وتجميع فعلي للعناصر حسب النوع المختار.
- حفظ تعديلات العرض والإعدادات محليًا مع معالجة تهيئة تمنع الكتابة فوق البيانات المحفوظة.
- مشغل مصغر وواجهة مشغل كاملة على مستوى النموذج الأولي.
- عرض الغلاف كمربع أو دائرة أو دائرة دوارة.
- تحرير اسم الأغنية والألبوم داخل بيانات النموذج الأولي.
- تطبيع قيم A-B loop داخل مدة المسار وتنسيقها بصيغة زمنية ثابتة.
- واجهة RTL عربية مع تصميم ليلي بنفسجي.

## الحدود المعروفة

- لا توجد بعد طبقة `MediaStore` لمسح ملفات الجهاز.
- لا يوجد تشغيل صوت فعلي أو تشغيل خلفي عبر Media3.
- القص والتصدير وتحرير الوسوم ما زالت تحتاج إلى Native Module؛ الواجهة لا تدّعي تنفيذها.
- بيانات المشغل الحالية تجريبية ولا تمثل مكتبة المستخدم الحقيقية.

## الخطوة الأصلية التالية

ينبغي إنشاء Native Module لأندرويد لمسح `MediaStore` وقراءة صورة الغلاف وتشغيل Media3 في foreground service، ثم ربطه بواجهة `Track` الحالية. بعد ذلك يمكن تنفيذ القص عبر Media3 Transformer أو FFmpeg وتحرير الوسوم عبر مكتبة أصلية متوافقة مع الصيغ المطلوبة.

## الترخيص والمصادر

يجب مراجعة تراخيص المشاريع المرجعية قبل دمج أي كود منها مباشرة. صُممت هذه النسخة كإعادة تنفيذ مستقلة للواجهة والتدفقات، مع الاستفادة من الأفكار العامة للمشروعات المفتوحة المصدر مثل Booming Music وPhonograph Plus وABLoopPlayer.
