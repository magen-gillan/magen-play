# magen-play

مشغل موسيقى محلي مفتوح المصدر لأندرويد بواجهة عربية وتجربة قابلة للتخصيص. يعرض المكتبة حسب الأغاني أو الألبومات أو المجلدات أو الفنانين، ويوفر مشغلًا مصغرًا، وأنماطًا متعددة لغلاف الأغنية، ومحررًا لبيانات المسار، وتدفقًا لقص الأغنية، وتكرار مقطع A-B.

## الحالة الحالية

هذا الإصدار هو نموذج أولي واجهة وتجربة استخدام يعمل داخل مشروع Expo SDK 54. بيانات المكتبة الحالية تجريبية لتوضيح الواجهة، بينما يحتاج الربط بملفات الجهاز إلى Native Module لأندرويد يقرأ MediaStore ويشغل Media3 في خدمة خلفية. كما يحتاج تحرير الوسوم والقص الفعلي إلى طبقة أصلية تتعامل مع صيغ الصوت وصلاحيات Android Storage.

## التشغيل

```bash
pnpm install
pnpm dev
```

للفحص المحلي:

```bash
pnpm check
pnpm lint
pnpm test
```

## المزايا الظاهرة

- اختيار الصفحة الابتدائية: الأغاني، الألبومات، المجلدات، أو الفنانون.
- عرض الغلاف كمربع أو دائرة أو دائرة دوارة.
- بحث محلي، مشغل مصغر، إعدادات ثيم، وتدفقات تحرير وقص وتكرار A-B.
- واجهة RTL عربية مع تصميم ليلي بنفسجي.

## الترخيص والمصادر

يجب مراجعة تراخيص المشاريع المرجعية قبل دمج أي كود منها مباشرة. صُممت هذه النسخة كإعادة تنفيذ مستقلة للواجهة والتدفقات، مع الاستفادة من الأفكار العامة للمشروعات المفتوحة المصدر مثل Booming Music وPhonograph Plus وABLoopPlayer.
