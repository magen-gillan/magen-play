# Spinning disc cover - credits

`DiscImageView` / `DiscStyle` are an original implementation. Their customization options were designed after
these open source projects (all Apache License 2.0); no code was copied:

| Option in Settings | Idea from |
|---|---|
| Disc grooves ("tracks"), rectangle <-> circle shape | [andremion/Music-Cover-View](https://github.com/andremion/Music-Cover-View) (`shape`, `trackColor`) |
| Disc ring color | [death14stroke/music-cover-view](https://github.com/death14stroke/music-cover-view) (`ringColor`, `strokeColor`, `ringWidth`) |
| Rotation speed | [iammert/MusicPlayerView](https://github.com/iammert/MusicPlayerView) (`setVelocity`) |
| Progress ring | [iammert/MusicPlayerView](https://github.com/iammert/MusicPlayerView) (`progressLoadedColor`, `progressEmptyColor`) |

Considered but not used: [smoliicek/vinyl](https://github.com/smoliicek/vinyl) (animated tonearm) - it has no license file.
